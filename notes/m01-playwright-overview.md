## M01: Playwright Overview

### What is Playwright?
* Developed by Microsoft as an end-to-end testing framework for modern applications.
* Supports cross-platform execution across Windows, Linux, and macOS environments.
* Automates major rendering engines, including Chromium, Firefox, and WebKit.

### Key Features
* Automatic waits eliminate the need for manual wait statements, reducing flaky tests.
* Mobile emulation allows testing responsive designs directly on simulated devices.
* Built-in debugging tools include screenshots, video recording, and trace viewers.
* Supports both headless and headful execution modes for flexible testing setups

### Capabilities & Use Cases
* Handles complex multi-domain workflows and Shadow DOM interactions seamlessly
* Fully supports comprehensive UI, functional, cross-browser, and API testing
* Highly useful for localization testing and gathering basic performance benchmarking insights

### Tool Comparison (vs. Cypress & Selenium)
* Unlike Cypress, Playwright supports multiple tabs, multiple windows, and parallel execution
* Unlike Selenium, Playwright includes automatic waiting, built-in mobile emulation, and a native test runner
